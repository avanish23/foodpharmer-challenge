# Local FSSAI documents

Place official FSSAI Advertising and Claims regulation PDFs in this directory or
in its subdirectories. FoodPharmer reads PDFs locally; it never downloads
regulations automatically.

Use only documents obtained from official FSSAI sources. The analyzer preserves
each PDF's filename, page number, detected section heading, and verbatim chunk
text in its retrieved evidence output.

PDF files in this directory are ignored by Git so locally supplied regulations
are not accidentally committed.
